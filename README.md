# 수업 응답 웹앱

만든 사람: **이효송** · 이용 조건: CC BY-NC 4.0 (`LICENSE.md`) · 출처를 밝히면 수업에 자유롭게 쓰고 고칠 수 있습니다(판매 금지). 화면 아래의 만든 사람 표시는 지우지 말아 주세요.

슬라이드를 띄우며 수업하고, 학생은 휴대폰·태블릿·노트북으로 그 쪽의 질문에 답하는 웹앱입니다.
교사는 화면에서 질문·설문·퀴즈를 직접 만들고, 응답을 실시간으로 모아 보고, 원하는 응답만 학생에게 공개합니다.

- **교사**: 이메일과 비밀번호로 로그인
  - **슬라이드 수업** 또는 **설문만** 만들기 (수업 코드는 자동으로 생김)
  - PowerPoint를 PDF로 저장해 올리면 쪽마다 슬라이드가 됨
  - 질문·설문·퀴즈(자동 채점) 만들기, 쪽 넘기기, 응답 모아 보기·공개, CSV 내려받기
  - 접속한 학생 이름 보기, 학생 비밀번호 초기화
- **학생**: 처음 한 번 학번 + 이름 + 숫자 4자리 비밀번호를 정하면 모든 수업에서 같은 비밀번호를 씁니다. 한 번 입장한 기기는 새 수업 링크·QR로 바로 들어오고, 어느 기기에서든 이어서 씁니다.
- **비용**: GitHub Pages(화면)와 Supabase(데이터) 무료 플랜으로 한 반 수업에 충분합니다.

## 파일 구성

| 파일 | 하는 일 | 고칠 일 |
|---|---|---|
| `index.html`, `student.js` | 학생 화면 | 없음 |
| `teacher.html`, `teacher.js` | 교사 화면 | 없음 |
| `common.js`, `app.css` | 두 화면이 함께 쓰는 기능과 모양 | 없음 |
| `vendor/` | PDF를 그림으로 바꾸는 도구(pdf.js) | 없음 |
| `setup.sql` | 데이터베이스 표, 보안 규칙, 슬라이드 저장소 | **1단계: 맨 아래 교사 이메일** |
| `config.js` | Supabase 연결 정보 | **2단계** |

## 1단계 · Supabase 만들기 (데이터 저장소)

1. [supabase.com](https://supabase.com)에 가입하고 **New project**를 누릅니다.
   - Region은 **Northeast Asia (Seoul)** 을 고르세요.
   - Database Password는 아무 데나 적어 두세요(이 웹앱에서는 쓰지 않습니다).
2. `setup.sql`을 메모장으로 열어 **맨 아래 줄의 `teacher@example.com`을 내 이메일(소문자)로 바꾸고** 저장합니다.
3. 왼쪽 메뉴 **SQL Editor**에 파일 전체를 붙여넣고 **Run**을 누릅니다. "Success"가 나오면 됩니다.
   - "destructive operation" 같은 경고 창이 나오면 그대로 실행하세요.
4. 교사 계정 만들기: **Authentication → Users → Add user → Create new user**
   - 2번에 적은 이메일과 내가 쓸 비밀번호를 넣고, **Auto Confirm User**에 체크합니다.
   - 비밀번호는 **이 웹앱에서만 쓰는 것으로 새로** 만드세요. 다른 사이트와 같은 비밀번호를 쓰면, 그 사이트에서 새었을 때 여기도 위험해집니다.
   - 비밀번호는 Supabase에 암호화되어 저장되고, 이 폴더의 파일이나 GitHub에는 어디에도 적지 않습니다.
5. 아무나 가입하지 못하게: **Authentication → Sign In / Providers**에서 **Allow new users to sign up**을 끕니다.

## 2단계 · config.js에 연결 정보 넣기

1. 대시보드 위쪽 **Connect** 버튼(또는 **Project Settings → API Keys / Data API**)에서 두 가지를 복사합니다.
   - **Project URL**: `https://abcdefgh.supabase.co` 모양
   - **Publishable key**: `sb_publishable_...` 모양
2. `config.js`를 메모장으로 열어 따옴표 안에 붙여넣고 저장합니다.

```js
const SUPABASE_URL = "https://abcdefgh.supabase.co";
const SUPABASE_KEY = "sb_publishable_xxxxxxxx";
```

> ⚠️ **secret 키(`sb_secret_...`, 예전 이름 service_role)는 절대 넣지 마세요.** 그 키가 있으면 누구나 모든 데이터를 읽고 지울 수 있습니다.
> publishable 키는 공개되어도 괜찮습니다. 보안은 setup.sql의 규칙이 지킵니다.

## 3단계 · GitHub에 올리기

1. [github.com](https://github.com)에 가입하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 저장소 이름(예: `class-response`)을 적고 **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 다음 화면의 **uploading an existing file**을 누릅니다.
4. 압축을 푼 폴더 **안의 파일들과 `vendor` 폴더를** 모두 끌어다 놓습니다. (폴더째 올리면 안 됩니다. 가장 흔한 실수입니다.)
5. **Commit changes**를 누릅니다.

> 무료 GitHub Pages는 저장소가 공개입니다. **학생 명단, 응답 CSV 같은 것은 절대 올리지 마세요.**
> 학생 응답과 슬라이드는 GitHub가 아니라 Supabase에 저장됩니다.

## 4단계 · GitHub Pages 켜기 (웹 주소 만들기)

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Source**: Deploy from a branch, **Branch**: `main` / `(root)` → **Save**.
3. 1~2분 뒤 위쪽에 주소가 나옵니다: `https://내아이디.github.io/class-response/`
   - 교사 화면: 주소 끝에 `teacher.html`
   - 학생 화면: 교사 화면의 **학생 접속 주소·QR**로 들어옵니다.

## 5단계 · 시험해 보기 (꼭!)

1. 교사 화면에 로그인 → **수업 설정 → 새로 만들기**에서 **슬라이드 수업**을 고르고 제목을 넣습니다.
2. PowerPoint에서 **파일 → 다른 이름으로 저장 → PDF**로 저장한 파일을 올립니다.
3. **질문·설문 만들기**에서 질문을 하나 만듭니다.
4. **수업 진행 → 학생 접속 주소·QR**을 휴대폰으로 찍어 학생처럼 입장하고 답을 저장합니다.
5. 교사 화면에 이름과 응답이 몇 초 안에 뜨는지 확인합니다.
6. **실습 학교에 가면 그 학교 와이파이에서 4~5번을 다시 해 보세요.**

## 쓰는 법

### 수업 진행
- **다음 ▶ / ◀ 이전**(또는 키보드 ← →)으로 넘기면 학생 화면도 따라 넘어갑니다.
- 오른쪽 **접속 중** 카드에 들어온 학생 이름이 보입니다. 초록색은 지금 화면을 열어 둔 학생, ✓는 이 쪽 질문에 답한 학생입니다.
- **학생에게 공개**를 누르면 학생 화면에도 친구들의 응답이 보입니다(기본은 이름 없이).
- **제출 마감**을 누르면 학생이 저장할 수 없습니다.
- **크게 보기**는 TV에 띄우기 좋은 큰 화면, **학생별 표**와 **CSV**는 누가 무엇을 냈는지 봅니다.

### 질문·설문 만들기
- **슬라이드 질문**(정해진 쪽 아래), **설문**(정답 없음), **퀴즈**(정답 표시, 자동 채점, 한 번만 제출, 해설)
- 질문 종류: 하나 고르기, 여러 개 고르기, 짧은 글, 긴 글
- **설문만** 수업은 슬라이드 없이 링크 하나로 설문·퀴즈를 받습니다.

### 학생 관리
- 비밀번호를 잊었거나 5번 틀려 잠긴 학생은 **비밀번호 초기화**. 쓴 답은 그대로 남습니다.
- 장난으로 만든 이름은 **삭제**(그 응답도 지워짐).

### 여러 반
- **수업 설정 → 다른 반용으로 복제**: 질문과 슬라이드는 그대로, 학생과 응답은 따로 모입니다.

## 꼭 알아 둘 것

- **개인정보**: 학생 이름을 외부 서비스에 모으는 것이므로, 쓰기 전에 **지도교사께 확인**을 받으세요. 이름 대신 별명을 쓰게 해도 됩니다.
- 학생에게 "**휴대폰 비밀번호나 생일은 쓰지 말라**"고 꼭 말해 주세요.
- **Supabase 무료 프로젝트는 1주일 동안 쓰지 않으면 일시 정지**됩니다. 오래 쉬었다면 수업 전날 대시보드에서 **Restore**.
- **인터넷이 끊기면 수업이 멈춥니다.** 같은 질문을 종이 활동지로도 준비해 두세요.
- 수업이 끝나면 **CSV로 응답을 내려받아** 보관하고, 필요 없는 수업은 지우세요.

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| "아직 연결되지 않았습니다" | `config.js`에 주소와 키를 넣고 GitHub에 다시 올렸는지 |
| "교사로 등록되지 않은 계정" | `setup.sql` 맨 아래 이메일이 로그인한 이메일과 같은지(소문자). 고쳐서 다시 Run |
| 교사 로그인이 안 됨 | Authentication → Users에 그 계정이 있고 Auto Confirm 했는지 |
| PDF 올리기가 안 됨 | setup.sql을 끝까지 실행했는지(슬라이드 저장소가 거기서 만들어짐), `vendor` 폴더를 올렸는지 |
| 학생이 "수업 코드를 찾지 못했습니다" | QR이나 링크로 들어오면 코드를 칠 필요가 없습니다 |
| 학생이 저장이 안 됨 | 교사 화면에서 "제출 열기" 상태인지 |
| 고친 파일이 반영되지 않음 | 1~2분 기다리고 새로고침(Ctrl+F5) |
